У Cloudflare нет приложения под Android. Это оно — нативный клиент их API, сделанный для того, чтобы починить DNS-запись или выключить правило файрвола, не разыскивая ноутбук.

<b>Чем управляет</b>

• Зоны — поиск, постраничная загрузка, тариф и статус, NS-серверы
• DNS — все 21 тип записей, у каждого своя форма: SRV спрашивает service, proto, priority, weight, port и target, а не одно пустое поле. Переключатель прокси прямо в строке, TTL, комментарии, метки, выгрузка BIND
• Кэш — очистка по URL, хосту, префиксу или тегу, а «очистить всё» — за подтверждением вводом слова
• Настройки зоны — режим SSL/TLS, HSTS, минимальная версия TLS, уровень кэширования, уровень защиты и другое
• Аналитика — трафик, доля попаданий в кэш, угрозы, коды ответов, страны, типы контента, события файрвола
• Защита — свои правила WAF и ограничение частоты: создать, включить, выключить, удалить. Правила доступа по IP
• Платформа разработки — скрипты Workers, маршруты и cron; проекты и деплойменты Pages; пространства KV с просмотром и правкой значений; D1 с SQL-консолью; бакеты R2
• Zero Trust — туннели с живым статусом коннекторов, приложения и политики Access, правила Gateway
• Трафик и TLS — page rules, балансировщики, комнаты ожидания, пакеты сертификатов, свои хостнеймы, DNSSEC
• Пересылка почты, виджеты Turnstile, политики оповещений

<b>И всё остальное тоже</b>

То, для чего нет отдельного экрана, всё равно доступно. Приложение носит с собой описание всего API Cloudflare — 3240 эндпоинтов — и строит настоящую форму по схеме каждого: типизированные поля, выпадающие списки для перечислений, отметки обязательных полей, диапазоны и преднаполненное тело запроса. Ничто не остаётся недостижимым только потому, что экран под это ещё не написан.

<b>Учётные данные не покидают устройство</b>

Вход по API-токену (рекомендуется) или Global API Key. И то и другое шифруется AES-256-GCM ключом, выведенным из вашего пин-кода через PBKDF2-HMAC-SHA256 за 210 000 итераций, и хранится только на этом телефоне.

Разблокировка отпечатком привязана к железу. Ключ хранилища обёрнут ключом Android Keystore, созданным с setUserAuthenticationRequired, а разворачивается через BiometricPrompt с CryptoObject — то есть проверку отпечатка обеспечивает защищённый элемент, а не приложение, рисующее окошко, которое можно обойти. Добавление нового отпечатка уничтожает ключ и возвращает к пин-коду.

Скриншоты, запись экрана и превью в списке недавних заблокированы по умолчанию. Облачный бэкап отключён, чтобы зашифрованные данные не уехали вместе с переносом устройства.

<b>Никакой телеметрии</b>

Ни аналитики, ни отправки отчётов о сбоях, ни рекламы, ни слежки. Приложение обращается к api.cloudflare.com и к dash.cloudflare.com — только когда вы сами нажимаете кнопку, открывающую панель в браузере. Больше в нём нет ничего, что выходит в сеть.

<b>Одно сознательное упущение</b>

Очереди офлайн-записи нет и не будет. Изменение DNS, поставленное в очередь в 09:00 и молча применённое в 14:00, когда вы уже починили всё другим способом, — худший баг, который может выпустить управляющее приложение. Без связи запись заблокирована, и об этом сказано прямо.
